# Learning entry example — not completed work

After a real session, add an object to entries.json:

```json
{
  "day": 1,
  "date": "2026-11-03",
  "summary": "Replace this with the concrete change you made",
  "learned": "Explain a decision or failure you can defend",
  "verification": "Record actual commands and their observed results",
  "assistance": "State what AI or another person did and what you verified",
  "evidence": ["notes/day-001.md"]
}
```

Use the actual session date and an existing nonempty file. Do not copy the placeholders as completion evidence. Session numbers need not equal calendar streaks. Never include private application records or credentials.
